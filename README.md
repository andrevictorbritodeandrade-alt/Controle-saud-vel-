# Rotina Saudável - Web App (React + Tailwind)

This is a Web rewrite of the biological optimization routine app, created with React, Vite, and Tailwind CSS. It is fully ready to be deployed to Vercel or any other static hosting provider.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## Vercel Deployment

You can deploy this project directly to Vercel. 
The build settings should be automatically detected as a Vite project:
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
